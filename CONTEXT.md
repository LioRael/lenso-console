# Lenso Console

Console composes application destinations and page-owned actions without owning their business authority.

## Language

**Dock preset**:
A user-named, ordered set of navigation destinations. A preset expresses the user's purpose, not an identity, permission set, application installation or page selection.
_Avoid_: Dock profile, navigation profile

**Navigation destination**:
An explicitly contributed application entry point available through Console navigation. Placing it in a preset does not grant access to it.

**Presentation preference**:
The user's choice of navigation mode and Dock placement, independent of which preset is active.
