# Surface Gateway contracts

These files are committed copies of Business API contracts owned by their
modules. The Console Surface Gateway uses the exact bytes to bind a request to
the contract digest before forwarding it to a connected service.

Update a copy only together with its owning module client, server validation,
Surface API Grant, and digest test.
