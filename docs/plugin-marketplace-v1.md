# Lenso Plugin Marketplace

Marketplace is maintained in the independent [lenso-marketplace repository](https://github.com/LioRael/lenso-marketplace). Its Web and Directory Plugins, native App, Workers host, publisher, tests and deployment configuration are owned there.

Console Agent owns target selection, installation tools and final authorization. It consumes signed catalog metadata through the public protocol; the Console build does not include Marketplace application source.

See the [Marketplace architecture](https://github.com/LioRael/lenso-marketplace/blob/main/docs/plugin-marketplace-v1.md) and [extraction record](https://github.com/LioRael/lenso-marketplace/blob/main/docs/migration.md).
