# Release Process

`LioRael/lenso-console` owns its npm packages and Console Service OCI image. It
does not use a repository-wide release plan, shadow registry, central publisher,
release nonce, or cross-repository receipt channel.

## npm workspace packages

Create a changeset for every user-facing package change:

```sh
pnpm changeset
```

The Changesets workflow opens or updates a version pull request. The public
packages are `@lenso/console-composition-api`,
`@lenso/console-module-api`, `@lenso/console-tokens`, and `@lenso/console-ui`.
Every public package declares this GitHub repository so npm Trusted Publishing
can verify its provenance, and the release command builds all four packages
before publishing them. The root `@lenso/console-web` package is private and is
versioned only when a Console Service OCI release is required. The workflow
uses OIDC and no long-lived `NPM_TOKEN`.

Existing public versions, tags, and historical changelogs are preserved. New
package changelog entries are generated by Changesets; package streams are
independent and internal workspace ranges are updated automatically.

## Console Service OCI image

The root private package version is the Console Service release version. When a
merged Changesets version update changes that version, the repository-local OCI
workflow:

1. builds `ghcr.io/liorael/lenso-console:VERSION` for `linux/amd64` and
   `linux/arm64`;
2. refuses to overwrite an existing version tag;
3. publishes the image with GitHub OIDC and build provenance;
4. generates `service/release-manifest.schema.json` output bound to the image
   digest, source commit, and Console contract digests; and
5. creates `lenso-console-service@VERSION` with the manifest attached.

The manifest and image digest are the installation source of truth. The old
central `lenso-release` runtime, Tegami plan, shadow mode, recovery workflow,
and shared receipt channel must not be restored.

## Cargo

The Console Service and its Console-owned Story crate are `publish = false`, so
this repository has no Cargo registry release stream. If a public Cargo crate
is introduced later, add a repository-local Release-plz workflow for that crate
without coupling it to npm or OCI publication.

## Local checks

```sh
pnpm install --frozen-lockfile
pnpm changeset status --output /tmp/lenso-console-changesets.json
pnpm format:check
pnpm lint
pnpm typecheck
pnpm build
pnpm test
pnpm service:check
```

To produce and inspect a local OCI archive without publishing:

```sh
RELEASE_COMMIT="$(git rev-parse HEAD)" \
RELEASE_VERSION="$(node -p 'require("./package.json").version')" \
pnpm release:artifacts
```
