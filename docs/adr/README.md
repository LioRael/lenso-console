# Architecture decision records

ADRs 0001–0005 document the former Service-oriented React Console. They remain
historical evidence but are not normative for the rebuilt Console. ADR 0002 was
superseded inside that former architecture; ADR 0006 supersedes its remaining
accepted decisions as part of the clean GPUI reconstruction.

The normative sequence for the rebuilt independent Console begins with
[ADR 0006](0006-rebuild-the-independent-console-with-gpui.md). Read
[`../architecture/gpui-console.md`](../architecture/gpui-console.md) for the
current architecture and [`../../CONTEXT.md`](../../CONTEXT.md) for canonical
language.
